# AWS Cost Intelligence - Frontend

Modern, high-performance SaaS FinOps dashboard engineered with React 18, TypeScript, Vite, Tailwind CSS, TanStack Query, and Recharts.

## Features
- Today's, Yesterday's, and Day Before Yesterday's cost indicators with +/- % deltas
- Multi-view chart engine: Daily Line Chart, Weekly/Monthly Bar Chart, Service Donut Chart, and Spend Scatter Plot
- Centralized deterministic AWS service color palette
- Deep Cost Records explorer with dynamic filtering and streaming CSV download
- FinOps Optimization recommendations with potential savings calculations
- AWS Budgets tracking & Anomaly timeline
- Dark Mode / Light Mode support

## Running Locally

```bash
npm install
npm run dev
```
Runs at `http://localhost:5173`.
